# 🛍️ Dynamic JavaScript REST API Product Store

A responsive product store web application built using HTML, CSS, and JavaScript. The application fetches product data from a public REST API and dynamically displays products with search, filtering, sorting, and cart functionality.

## 🚀 Features

- 🔄 Fetch products using REST API
- ⚡ Async/Await and Fetch API
- 🔍 Real-time product search
- 📂 Category filtering
- 💰 Price sorting
- 🔤 Name sorting
- 🛒 Add products to cart
- 💾 Cart persistence using LocalStorage
- ⏳ Loading state
- ⚠️ Error handling
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- Fetch API
- Async/Await
- DOM Manipulation
- LocalStorage
